# Product Vision - Gorgonaut

## Overview

Gorgonaut is a context-aware expert system that helps knowledge workers discover, apply, and master cognitive tools (Mind Tools) for problem-solving, decision-making, creativity, and productivity.

## Core Value Proposition

Transform the Mind Tools corpus (books, frameworks, techniques) into an intelligent, adaptive system that:
- Understands user context (task, constraints, emotional state)
- Recommends relevant cognitive tools and frameworks
- Guides users through tool application
- Tracks skill development and capability building over time

## Target Users

### Primary Stakeholders
1. **Individual Knowledge Workers** - Professionals seeking better decision-making and problem-solving capabilities
2. **Managers & Team Leads** - Leaders managing projects and developing team capabilities
3. **Consultants & Coaches** - Practitioners helping clients solve complex problems
4. **Students & Learners** - Individuals building transferable meta-skills

### User Needs
- Quick access to relevant tools for current problems
- Guidance on when and how to apply specific techniques
- Structured workflows combining multiple tools
- Progress tracking and skill gap identification
- Personalized learning paths for meta-skill development

## Product Components

### 1. Mind Tools Knowledge Graph
Semantic ontology capturing:
- Tools and techniques (SCAMPER, SWOT, Gantt charts, etc.)
- Meta-skills (creativity, decision-making, project management)
- Problem types and solution patterns
- Relationships between tools, problems, and outcomes

### 2. Expert System Engine
Four-layer architecture:
- **Context Engine** - Understands user situation and frames problems
- **Tool Synthesis Engine** - Selects and composes tool workflows
- **Decision/Action Layer** - Generates actionable plans and artifacts
- **Capability Building Layer** - Tracks growth and reinforces learning

### 3. User Interfaces
- **Web Application** - Primary interface for tool discovery and application
- **API** - Programmatic access for integrations
- **CLI Tools** - Developer utilities and validation

## Success Metrics

### User Outcomes
- Faster problem resolution
- Higher quality decisions
- Improved meta-skill proficiency
- Increased confidence in tool selection

### System Metrics
- Tool recommendation accuracy
- User engagement and retention
- Workflow completion rates
- Skill progression velocity

## Branding & Mythology

**Gorgonaut** draws from Greek mythology:
- **Gorgons** - Transformative power (turning challenges to stone/solutions)
- **Argonaut** - Journey of discovery and mastery
- Represents the hero's journey through cognitive development

## Principles

1. **Context-Aware** - Recommendations adapt to user situation
2. **Stakeholder-Sensitive** - Different guidance for different roles
3. **Evidence-Based** - Grounded in established frameworks and research
4. **Capability-Building** - Focus on long-term skill development, not just quick fixes
5. **Composable** - Tools can be combined into powerful workflows
6. **Transparent** - Clear rationale for recommendations
